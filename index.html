Regras para conduzir

  • Escute 80% do tempo. O diagnóstico é dele, não seu.
  • Pergunte “por quê?” duas vezes nas respostas importantes.
  • Anote as palavras exatas do cliente para usar na tese.
  • Se pedir para ver um imóvel: “Prefiro te mostrar o que faz sentido para você. Por isso a tese vem primeiro.”
  • A ordem é flexível. Use o roteiro como checklist.
  • Clientes mais formais: “o senhor” ou “a senhora” até ser convidado a mudar.
